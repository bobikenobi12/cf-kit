cf-kit

A C++ workspace for Codeforces. Import problems from your browser, run the samples with one key, and stress test your solution against a brute force.

Install (macOS, needs git, Python 3.9+ and GCC):

curl -fsSL https://raw.githubusercontent.com/bobikenobi12/cf-kit/main/install.sh | bash
